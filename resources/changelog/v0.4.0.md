## 新功能

### 修訂編輯可用搜尋選擇既有 Vertex／Edge（#61）

- 新增圖實體搜尋 API：`GET /graph/search/vertices`、`GET /graph/search/edges`
- 新增 `AgeEntitySearch` 元件與 `GraphEntitySearchService`，修訂草稿中刪除／屬性操作與建立 Edge 時，可用顯示名稱或 ID 搜尋選取既有節點與邊，不再只能手動輸入 AGE ID
- 搜尋既有節點／邊前需先選擇類型；未選類型時搜尋框停用
- 建立 Edge 時：先選 Edge 類型後，起迄點會顯示對應的 Vertex 類型限制，並只搜尋該類型
- 選取類型後即可過濾屬性選項
