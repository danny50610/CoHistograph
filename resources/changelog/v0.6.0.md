# 新功能

## 實作 CoHistograph MCP Server（Passport OAuth）（#45）

- 以 Laravel MCP + Passport OAuth 提供 HTTP 端點 `/mcp`，供 Cursor 等 AI 客戶端查詢圖譜與協助修訂工作流
- 涵蓋 Schema／Graph／Revision 工具（搜尋類型與實體、鄰居、修訂 CRUD、action 增刪改排序、驗證、送審、重開等）與 `ExploreVertexContext` prompt
- Revision 新增 `is_ai_assisted`：經 MCP 建立或編輯會標記為 `true`（sticky），列表／詳情顯示 AI badge

## 新增 ENUM 屬性型別（#71）

- 屬性型別新增 ENUM（多選）；選項存於 `enum_options`，AGE 以 list 儲存選取值
- 支援選項啟用／停用，以及 `min_selections`／`max_selections` 選取數量上下限
- Schema 列表、Visualization 與修訂編輯／審核皆依 label 顯示；修訂 value 改為 jsonb 以支援原生 list／scalar

## EdgeType 支援多組起迄 VertexType（#73）

- Edge Type 可設定多組起迄 Vertex Type pair，不再限單一組合
- 刪除／更新時的 AGE 資料檢查改為依 Vertex pair 比對
- 修訂 `create_edge`：起迄點依所選 pair 連動篩選

## 可編輯首頁說明文字（#74）

- 新增 `system_configs`（JSON）與強型別 `HomepageConfig`
- 後台「首頁設定」可編輯 tagline（權限 `system-config.manage`）

## 常見問題 (FAQ) 可從後台編輯（#75）

- 公開 `/faq` 改由資料庫讀取
- 後台可 CRUD、排序與隱藏項目（權限 `faq.manage`）

# 錯誤修正

## 修訂驗證誤報 Vertex 不存在（#73）

- AGE graphid 改以字串傳遞，避免 JS `Number` 精度失真導致誤報

## MCP／OAuth 相容性（#45）

- 允許 Cursor 等自訂 OAuth redirect scheme
- OAuth 路由還原預設 PostgreSQL `search_path`，避免認證失敗
- MCP HTTP 端點固定為品牌無關的 `/mcp`

# 部署注意

1. 執行 migration
2. `php artisan app:apply-role-and-permission-command`（同步 `system-config.manage`、`faq.manage`）
3. `php artisan passport:keys`
4. 若要接 MCP：設定 Passport／OAuth，並在客戶端 `mcp.json` 指向 `https://<domain>/mcp`
