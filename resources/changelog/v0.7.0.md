## 新功能

### TIME 屬性型別

新增僅儲存時間（`HH:mm:ss`）的 `PropertyType::Time`，與 `DATE`、`MONTH_DAY`、`TIMESTAMPTZ` 並列，適用於營業時間、每日時刻等不需綁定日期或時區的場景。

- AGE 以字串儲存（例如 `14:30:00`）；讀出時轉為 `CarbonImmutable`（sentinel date `2000-01-01`）
- 輸入支援 `HH:mm` 或 `HH:mm:ss`，寫入前正規化為 `HH:mm:ss`
- 修訂編輯 UI 使用 `<input type="time">`
- 驗證、儲存與顯示邏輯整合於 `PropertyValueCaster`

### MCP：`draft-revision` Prompt

新增可重複使用的 MCP Prompt，引導 AI 依標準流程撰寫知識圖譜修訂：

1. 查詢 schema（vertex / edge types 與屬性）
2. 搜尋既有圖資料，避免重複建立
3. 建立或延續 draft revision
4. 一次新增一筆 action（不覆寫整份 actions 列表）
5. 驗證修訂內容
6. 提交前向使用者確認

透過 `goal`（必填）與 `title`（選填）參數啟動，並明確提醒不可直接寫入 Apache AGE。

## MCP 改善

### ENUM 屬性完整支援

- **Schema 查詢**：`search-vertex-types` / `search-edge-types` 在 `include_properties=true` 時，回傳 `enum_options`、`min_selections`、`max_selections`
- **修訂 action**：`value` schema 改為 union 型別，允許 ENUM 以 `string[]` 傳入（例如 `["rock", "jazz"]`）
- AI 客戶端現在可以透過 MCP 為 ENUM 屬性設定多選值

### 說明與文件對齊

- 釐清 `validate-revision` 為選用步驟；`add` / `update` revision action 的回應已含驗證結果
- `submit-revision` 說明改為會自行再驗證，不必強制先呼叫 `validate-revision`
- `value` schema 將 array 型別置前，並附上 ENUM 範例 `["rock", "jazz"]`
- Server instructions 與 `.spec/mcp.md` 同步更新

## 修正

### 手機版導覽列無法展開

Bootstrap 5 需要 `data-bs-toggle`，原先誤用 Bootstrap 4 的 `data-toggle`，導致 collapse 無法觸發。已修正 `navbar` 元件。

## 升級說明

- 無需執行額外 migration；`TIME` 為新增 enum case，不影響既有資料
- 若使用 MCP 操作 ENUM 屬性，請確認客戶端以 **JSON array** 傳入選取值，而非單一字串
- 建議 MCP 客戶端採用 `draft-revision` prompt 以取得一致的修訂撰寫流程
