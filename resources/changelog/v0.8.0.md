## 新功能

### 公開更新紀錄

頁尾新增「更新紀錄」，依版本由新到舊列出說明，並連到對應的 GitHub Release。

### 個人資料與顯示名稱

- 已驗證的使用者可從選單進入個人資料，自行修改顯示名稱與密碼
- 註冊不再要求輸入名稱，改由信箱本地端自動產生唯一顯示名稱，之後仍可在個人資料修改
- `users.name` 改為唯一；註冊、個人資料與後台更新都會檢查，避免畫面上同名混淆

### 首頁介紹

首頁在既有標語下方補上「這是什麼」、「我能做什麼」與「怎麼開始」，協助第一次造訪的人了解平台與下一步。

### 修訂重複邊／節點軟性警告

草稿驗證與審核時，若即將建立的邊或節點與既有資料重複，會以黃色警告提示。警告不影響驗證是否通過，也不阻擋提交或接受。

- `DUPLICATE_EDGE`：相同邊類型與起迄點（方向敏感，不比較屬性）
- `DUPLICATE_VERTEX`：同類型且顯示名稱相同（該類型需設定 `show_property_name`；空名稱不警告）
- 本修訂內先前已刪除的對象不計入衝突
- MCP 驗證結果新增 `action_warnings`，同樣不影響 `is_valid`，也不阻擋 `submit-revision`

## 修正

### 修訂動作顯示邊的端點名稱

建立邊的動作在修訂詳情與審核頁會顯示起迄節點的顯示名稱，不再只顯示 AGE ID。

### 修訂編輯視窗誤關

- 從輸入框拖曳選取文字、並在 backdrop 放開滑鼠時，視窗不再關閉
- 關閉視窗前若有未儲存的變更，會先請使用者確認

### 依賴套件安全性更新

更新 Guzzle、CommonMark 與前端依賴，修補已知安全公告。
